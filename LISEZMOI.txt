BJJ TATAMI - jeu de jiu-jitsu bresilien pour Mega Drive (SGDK 2.11)
==============================================================================

COMPILER (Windows)
  1. Telecharger SGDK 2.11 : https://github.com/Stephane-D/SGDK/releases
     et le decompresser, par exemple dans C:\SGDK
  2. Installer Java (necessaire a rescomp, l'outil qui convertit les images).
  3. Ouvrir une invite de commandes dans ce dossier :
        set GDK=C:\SGDK
        build.bat
  4. La ROM est creee dans out\rom.bin

  Linux/macOS : utiliser SGDK via marsdev ou l'image Docker de SGDK,
  puis "make -f $GDK/makefile.gen" dans ce dossier.

JOUER
  RetroArch (coeur Genesis Plus GX ou PicoDrive) ou BlastEm.
  Manette 3 boutons suffit.

MENU (ecran titre)
  START : menu. HAUT/BAS : choisir, GAUCHE/DROITE : changer, A : valider.
  1 JOUEUR / 2 JOUEURS (manette 2) / NOM DU JOUEUR 1 (sauvegarde) / NIVEAU / DUREE.
  Sans toucher a rien pendant 15 s : combat de demonstration.

SELECTION
  GAUCHE/DROITE : categorie de poids IBJJF (Galo -> Pesadissimo)
  HAUT/BAS : combattant (3 par categorie, chacun ses stats et sa specialite)
  Stats : GAR garde, PAS passage, LUT lutte, SOU soumission, CAR cardio.

LE PRINCIPE (facon arcade)
  Chaque attaque SE VOIT VENIR : l'attaquant clignote et une icone de bouton
  apparait au-dessus de ta tete. Appuie sur le bouton montre AVANT que l'attaque parte.
  - Contre normal : "BLOC", l'attaquant est sonne, tu gagnes une OUVERTURE.
  - Contre au dernier moment : CONTRE PARFAIT ("CONTRA!") + avantage + ouverture longue.
  - Ouverture (tu brilles en dore) : ta prochaine technique part tout de suite, imparable.
  - Appuyer sur C pour rien = tu te decouvres un instant.

DEBOUT
  GAUCHE/DROITE : se deplacer       B tenu (pres de lui) : prendre les prises
  A : double-leg   BAS+A : single-leg   HAUT+A : projection judo (il faut des prises)
  BAS+B : tirer la garde (il faut des prises)
  Defense : C contre double et single-leg, HAUT+C contre le judo (l'icone te le dit).

AU SOL
  Les actions possibles s'affichent en bas : ^ = HAUT (ou rien), > = COTE, v = BAS.
  A + direction : technique (passer, monter, balayer, sortir, se relever...)
  B + direction : soumission
  FEINTE : pendant ta preparation, rappuie A ou B dans une autre direction.
  Defense : C + la fleche affichee au-dessus de ta tete.

SOUMISSION : BRAS DE FER
  L'attaquant martele A, le defenseur martele C. Jauge ECHAPPE <-> TAPE.
  Parfois une fleche apparait au-dessus d'un combattant : l'appuyer vite = gros bonus.

SUPER TECHNIQUE
  La jauge sous les points se remplit avec les techniques et les contres.
  Pleine (elle clignote, icones B C) : B+C ensemble = technique signature du combattant :
  cinematique, puis enchainement automatique jusqu'a sa soumission favorite.

SOUFFLE ET CARDIO (barres sous les noms)
  Chaque effort coute du souffle ; il ne remonte jamais au-dessus du cardio,
  qui baisse pendant le combat (moins vite si gros cardio).
  Essouffle : preparations plus lentes (plus faciles a contrer), soumissions plus faibles.

REGLES
  Points IBJJF : projection 2, balayage 2, genou au ventre 2, passage 3, montee 4, dos 4.
  Avantages : garde ouverte, soumission presque reussie.
  Penalite toutes les 30 s sans rien tenter (2e = avantage adverse, 3e = 2 points).
  Fin du temps : points, puis avantages, puis penalites, puis decision des arbitres.

MUSIQUE DE L'ECRAN TITRE
  Extraite de "Jiu-Jitsu Evolucao" : l'intro (0 a 11,3 s) jouee une fois, puis
  une boucle de 8,4 s (11,31 s a 19,68 s), en PCM 8 bits 13,4 kHz comme les voix
  digitalisees des jeux Mega Drive. Pas d'IA d'isolation disponible : seule
  l'intro, qui semble deja instrumentale, est utilisee.
  Pour utiliser une autre partie du morceau :
    1. Isoler l'instrumental chez toi (Ultimate Vocal Remover, gratuit, Windows).
    2. python3 tools/convert_music.py instrumental.wav DEBUT_BOUCLE FIN_BOUCLE
    3. Recompiler. Penser a couper la boucle pile sur un temps fort.
  ROM : environ 260 Ko de musique (430 Ko de sons au total). Garde ce morceau pour un usage perso :
  ne diffuse pas la ROM publiquement sans l'accord de l'artiste.

PUBLIC (pendant le match)
  Extrait de "Final Brasileiro Kids CBJJ 2024" (son de salle, sans commentaire) :
  ambiance vers 0'51", petite acclamation vers 5'31", grosse vers 4'45".
  Driver PCM4 de SGDK : voie 1 = ambiance en boucle (3,6 s), voie 2 = acclamations.
  - L'ambiance monte pendant les luttes et apres chaque action.
  - Petite acclamation : projection, balayage, passage, montee, dos, sortie.
  - Grosse acclamation : fin du match.
  Volumes reglables dans crowdUpdate() et crowdStart().
  Meme remarque que pour la musique : usage perso uniquement.

FICHIERS
  src/main.c            boucle principale
  src/match.c           le combat (debout, sol, soumissions, IA)
  src/screens.c         titre, nom, selection, versus, resultat
  src/roster.c          les 27 combattants (noms et stats modifiables)
  src/ui.c              textes, palettes, manettes, sons, sauvegarde
  res/resources.res     liste des images pour rescomp
  res/bg, res/sprites   images (PNG 16 couleurs)
  res/music             musique de l'ecran titre (WAV 13,4 kHz)
  res/sfx               bruits du public (WAV 16 kHz)
  tools/gen_art.py      regenere les sprites et le dojo (python3 + Pillow)
  tools/gen_title.py    regenere l'ecran titre
  tools/convert_music.py convertit un morceau en musique d'ecran titre

REGLAGES FACILES (src/match.c)
  topMoves / botMoves  transitions au sol : nom, position d'arrivee, points, difficulte
  topSubs / botSubs    soumissions par position
  cpuDeny / cpuRead    a quel point le CPU bloque et lit tes attaques (par niveau)
  cpuReact / cpuEscape vitesse du CPU dans le mini-jeu de soumission
  STALL_FRAMES         delai avant penalite de passivite
  Les combattants se modifient dans src/roster.c.
